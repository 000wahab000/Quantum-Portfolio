# Research: Brandhofer et al., "Benchmarking the performance of portfolio optimization with QAOA" (arXiv:2207.10555; QIP 22:25, 2023)

## Formulation
- **Cost:** F(z) = q·Σ_ij z_i z_j σ_ij − (1−q)·Σ_i z_i μ_i, with z ∈ {0,1}^n. The paper uses q = 1/3 throughout.
- **Budget:** Σz_i = B. Instances are n=5, B=2 (10 feasible states) and n=10, B=5 (252 feasible states).
- **Soft constraint:** F^(A) = F + A(Σz − B)². Used with the standard X mixer and the |+⟩^n initial state.
- **Hard constraint:** XY mixer (ring / parity-ring / full / QAMPA) with a **Dicke initial state |D^n_B⟩**. The state never leaves the feasible Hamming-weight subspace, so the **budget penalty A has no effect** on the dynamics.
- **Penalty rule:** choose A so that F^(nf)_min ≥ ½(F_min + F̄_feasible), refined iteratively (Eqs. 11 and 13). This is computed by brute force, which is fine for n ≤ ~20.
- **Ising mapping:** z_i → (1+Z_i)/2. Global scaling λ = ΔM/ΔF (the paper uses λ = 6 for n=10). We should ablate λ vs 1 and normalise the Hamiltonian so γ ranges are comparable.

## QAOA practice
- **Depth:** p up to 7.
- **Initialisation:**
  - p=1: 100-point grid on the linear-ramp ansatz (γ_i = m1·x_i, β_i = m2(1−x_i), x_i=(2i−1)/2p).
  - p≥2: best of four strategies: (i) interpolation from p−1, (ii) linear-ramp fit, (iii) quadratic ansatz, (iv) previous optimum padded with zeros, which guarantees ⟨F⟩ never gets worse with depth.
  - Rescale the parameters so Σ|γ| = Σ|β|.
- **Optimisers:**
  - SLSQP on statevector (best).
  - Nelder-Mead with shots (simplex 0.5, maxiter 10·2p).
  - COBYLA in the noise study.
- **Shots:** 1000 shots barely hurt results at n ≤ 10.

## Metrics (adopt)
- **Approximation ratio:** r(z) = (F(z) − F_max)/(F_min − F_max) if feasible, else 0. F_min and F_max are taken over **feasible** states. Report the expectation of r over the sampled distribution.
- **P(opt):** probability of measuring the optimal bitstring.
- **Feasibility rate:** the paper omits it; we add it.
- **Statistics:** mean ± std over ≥ 20 random instances.

## Findings
- Noiseless: full-XY and QAMPA beat the standard mixer at every p. At n=10, B=5, p=7 they reach r ≈ 0.98 and P ≈ 0.6.
- Under depolarising noise the XY advantage disappears as p grows. The crossover with the standard mixer is at η ≈ 0.001–0.003 per gate for p=3–7. Ring and parity-ring XY degrade less than full XY because their circuits are shallower.
- Harder instances have a smaller spread of μ and correlations.
- **No quantum advantage claimed.** All experiments are n ≤ 10, in-sample, with no transaction costs.

## Regression instance (from the paper's Tables 1–2)
- Assets: LIN.DE, BAYN.DE, VNA.DE, MTX.DE, MUV2.DE, with q = 1/3 and B = 2.
- Brute force gives optimum {LIN, VNA}, F_min = −0.22608, F_max = 0.08191 and F̄ = −0.08986.
- Use it as a unit-test fixture if we transcribe the μ/Σ values.

## Implications for our build
1. Implement **two QAOA variants**:
   - Standard X mixer + penalty QUBO. This is the PS baseline and the noise-robust option.
   - XY mixer (ring/full) + Dicke state. Exact cardinality, as the POC promised.
2. Sector caps, lots and costs stay as penalties in **both** variants. Tune the penalties with the brute-force rule when n ≤ 20, and with a heuristic bound otherwise.
3. **Initial-point strategies to compare** (the PS needs ≥2):
   - random
   - linear-ramp / TQA
   - layer-wise interpolation from p−1
   - warm start: CVXPY relaxation → Egger-style warm-start QAOA (initial state + mixer biased by the relaxed solution). This is a declared, legitimate warm start.
4. **Optimisers to compare** (the PS needs ≥2): COBYLA, SPSA, Nelder-Mead / SLSQP on statevector.
5. **Reproduce** Fig 2/3-style plots (1−r and P vs p) and Fig 6/7-style noise plots (r and P, ideal vs fake-backend).
