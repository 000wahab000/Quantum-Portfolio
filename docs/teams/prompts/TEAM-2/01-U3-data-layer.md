## Approach

1. `fetch_snapshot.py`: ONE batched `yf.download` for the 50 tickers plus `^NSEI`, start 2023-09-01, end 2026-10-08 (end is exclusive; last bar 2026-10-07), `auto_adjust=True`. The result has MultiIndex columns `(Price, Ticker)` in alphabetical ticker order, so take `df["Close"][tickers]` to restore input order. Write `backend/data/snapshot/prices.parquet`. Run it once with network. Resolve paths from `__file__` (repo path has spaces).
2. `universe.load_universe` reads `backend/data/nifty50.csv` into 50 `Asset(ticker, symbol, name, sector)` items (official sectors).
3. `prices.load_prices`: read the cache (`backend/data/cache/`, gitignored), then the snapshot, then fall back to live; `refresh=True` tries live first and writes the cache; any live failure falls back to the snapshot. Report `source` ("cache" | "snapshot" | "live") and `as_of` (last date in the data).
4. `risk.build_market`: slice the windows strictly by date (est 2023-10-01..2025-09-30, test 2025-10-01..2026-09-30, both inclusive).
   - Exclude a ticker with more than 5% missing rows in the estimation window (`excluded[ticker] = reason`).
   - Forward-fill gaps of up to 3 days (`ffill(limit=3)`; `filled[ticker] = count`).
   - Exclude `TMPV.NS` by default (reason: demerger on 2025-10-14 breaks the price series in the test window).
   - Drop any remaining NaN return rows and document that one rule in the module docstring.
   - Daily log returns; `mu = mean * 252`, `sigma = cov * 252`, from the estimation window only.
   - `est_end_prices` = last estimation-window close; `test_returns` = simple daily returns over the test window; `benchmark_test_returns` from `^NSEI`.
   - Fill `Market(tickers, sectors, mu, sigma, est_end_prices, test_returns, benchmark_test_returns, excluded, filled, windows, source, as_of)`.

## Interfaces

- Provide (section 1.2): `load_universe() -> list[Asset]`; `load_prices(tickers, start, end, refresh=False) -> PriceData(close, source, as_of)`; `build_market(tickers, windows=DEFAULT_WINDOWS) -> Market`; `Market.subset(tickers)`; constants `RF`, `C_BUY`, `C_SELL`, `DEFAULT_WINDOWS`.
